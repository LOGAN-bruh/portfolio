Guessing Game: Exception Loop Safety

Engine Architecture

Constructed an exception-safe application engine preventing runtime environment failures due to unexpected terminal values.

Design Decisions

  • Input Sanitization Guards: Wrapped keyboard string acquisition modules within try-except layers to safely catch text input conversion faults instead of crashing the program execution frame.
  • State Reset Routines: Wired immediate reset loop triggers handling active attempt counts and initialization flags upon completing game runs.
